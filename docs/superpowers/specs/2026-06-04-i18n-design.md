# Internationalisation (EN / KA / HE) — Design Spec

**Date:** 2026-06-04  
**Status:** Approved

## Overview

Add English, Georgian, and Hebrew language support using **next-intl** in no-routing mode. Locale is stored in a `NEXT_LOCALE` cookie (1-year, path `/`). A language switcher dropdown (EN / KA / HE) lives in the Navbar. Hebrew gets `dir="rtl"` on `<html>`; Georgian and English are LTR.

## Decisions

| Question | Decision |
|---|---|
| Languages | English (`en`), Georgian (`ka`), Hebrew (`he`) |
| Locale storage | Cookie `NEXT_LOCALE`, falls back to `en` |
| Routing | None — no URL changes, no middleware |
| Library | next-intl v3 (no-routing mode) |
| Switcher placement | Navbar (left of avatar dropdown) |
| RTL | Hebrew only — `dir="rtl"` on `<html>` |

## Section 1: next-intl Setup

### Install

```bash
npm install next-intl
```

### `next.config.ts`

```typescript
import createNextIntlPlugin from 'next-intl/plugin'
import type { NextConfig } from 'next'

const withNextIntl = createNextIntlPlugin('./i18n/request.ts')

const nextConfig: NextConfig = {}

export default withNextIntl(nextConfig)
```

### `i18n/request.ts`

```typescript
import { getRequestConfig } from 'next-intl/server'
import { cookies } from 'next/headers'

const SUPPORTED = ['en', 'ka', 'he'] as const

export default getRequestConfig(async () => {
  const cookieStore = await cookies()
  const raw = cookieStore.get('NEXT_LOCALE')?.value ?? 'en'
  const locale = (SUPPORTED as readonly string[]).includes(raw) ? raw : 'en'

  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default,
  }
})
```

### `app/layout.tsx`

Convert to async server component. Add `NextIntlClientProvider`, dynamic `lang`/`dir`:

```typescript
import type { Metadata } from 'next'
import { Inter } from 'next/font/google'
import { NextIntlClientProvider } from 'next-intl'
import { getLocale, getMessages } from 'next-intl/server'
import { Providers } from '@/components/providers'
import './globals.css'

const inter = Inter({ subsets: ['latin'] })

export const metadata: Metadata = {
  title: 'FamilyRoots — Discover Your Family History',
  description: 'Build, explore, and share your family tree with AI-powered tools',
}

export default async function RootLayout({ children }: { children: React.ReactNode }) {
  const locale = await getLocale()
  const messages = await getMessages()

  return (
    <html lang={locale} dir={locale === 'he' ? 'rtl' : 'ltr'}>
      <body className={inter.className}>
        <NextIntlClientProvider locale={locale} messages={messages}>
          <Providers>{children}</Providers>
        </NextIntlClientProvider>
      </body>
    </html>
  )
}
```

Note: `Inter` covers Latin (English). Georgian (Mkhedruli script) and Hebrew characters fall back to system fonts — both are well-supported on modern OS. No additional font packages needed for MVP.

## Section 3: New Components

### `components/layout/LanguageSwitcher.tsx`

```typescript
"use client"
import { useRouter } from "next/navigation"
import { useLocale } from "next-intl"
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select"

const LANGUAGES = [
  { code: "en", label: "EN" },
  { code: "ka", label: "KA" },
  { code: "he", label: "HE" },
]

export function LanguageSwitcher() {
  const router = useRouter()
  const locale = useLocale()

  function handleChange(newLocale: string) {
    document.cookie = `NEXT_LOCALE=${newLocale};path=/;max-age=${60 * 60 * 24 * 365}`
    router.refresh()
  }

  return (
    <Select value={locale} onValueChange={handleChange}>
      <SelectTrigger className="w-20 h-8 text-sm">
        <SelectValue />
      </SelectTrigger>
      <SelectContent>
        {LANGUAGES.map(({ code, label }) => (
          <SelectItem key={code} value={code}>{label}</SelectItem>
        ))}
      </SelectContent>
    </Select>
  )
}
```

## Section 4: Component Translation Pattern

**Client components** — call `useTranslations("namespace")` at top:

```typescript
// PersonForm.tsx (already "use client")
import { useTranslations } from "next-intl"

export function PersonForm(...) {
  const t = useTranslations("person")
  // ...
  <Label>{t("firstName")} *</Label>
  <Button>{loading ? t("saving") : t("save")}</Button>
}
```

**Server components** — call `getTranslations("namespace")` (async):

```typescript
// Sidebar.tsx (already async server component)
import { getTranslations } from "next-intl/server"

export async function Sidebar() {
  const t = await getTranslations("nav")
  const session = await auth()
  // ...
  { href: "/dashboard", label: t("dashboard"), icon: Home },
```

**Navbar** — already `"use client"`, use `useTranslations("nav")`.

## Out of Scope

- Dashboard, Profile, Settings, DNA pages (minimal string content)
- Date/number formatting per locale
- Font loading for Georgian/Hebrew scripts (system fonts used)
- RTL layout mirroring for complex UI (canvas, tree nodes)
